A program that writes one word, the word an ex would use to describe you,
to `/output/entry.txt`, for the make.fun competition
[One Word From Your Ex](https://make.fun/bounty/u-brave-eagle-12-one-word-from-your-ex-cfd97ba2).

Run it with Python 3:

```
python3 main.py
```

It writes the word below to `/output/entry.txt` (or to the path given as
the first argument, or `$OUTPUT_PATH`). No network, no clock, no
randomness. The word is 11 characters, inside the 1 to 24 gate, and the
file holds exactly the word, with no trailing newline and nothing else.

## The word

```
forgettable
```

Why this word: every ex reaches for "toxic" or "selfish". "Forgettable"
is the sharper self-own. Not hated, not missed, just not remembered.
It lands instantly, it stings because it might be true, and it is the
one verdict an ex could give that no comeback fixes.
